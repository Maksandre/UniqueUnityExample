# Unique Unity Example

Unity project demonstrating Unique Network integration using the Polkadot SDK for Unity.

## Dependencies

- **Polkadot SDK for Unity**: [Wiki](https://github.com/ajuna-network/Polkadot.Unity.SDK/wiki)
- **Unique Extension**: [Substrate.Unique.NET.Extension](https://www.nuget.org/packages/Substrate.Unique.NET.Extension/) v1.17008.0

## Features

- Connect to Unique Network via WebSocket
- Send UNQ transfers using mnemonic authentication
- Real-time transaction status updates
